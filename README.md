# Chinmai JL — Cinematic Developer Portfolio

Responsive neon-style portfolio for Chinmai JL, Python Developer fresher. Includes skills, selected projects, education/internship, contact links, animated 3D-inspired hero, and motion pause control.

## Publish with GitHub Pages
In the repository, open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then Save. The site will be available at https://chinmai-jl.github.io/chinmai-portfolio/ after Pages finishes publishing.

## Notes
Resume download expects `assets/Chinmai_JL-Resume.pdf`. Keep the `assets` folder alongside `index.html`.
